# Digitaliko

Custom software and AI agents for companies in Slovakia, Czechia and beyond. Seniors work with AI agents, every project is led by a senior, and the code is yours from day one.

## Open source
- [car-logos-dataset](https://github.com/filippofilip95/car-logos-dataset) - car brand logos in several sizes with a JSON index
- [claude-code-production-starter](https://github.com/Digitaliko/claude-code-production-starter) - Next.js starter with the guardrails AI agents need in production
- [skills](https://github.com/Digitaliko/skills) - Claude Code skills for harness engineering, code review and deployment
- [superfaktura-mcp](https://github.com/Digitaliko/superfaktura-mcp) - MCP server for the SuperFaktura invoicing API
