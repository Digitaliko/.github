# Digitaliko

Custom software and AI agents that work for you.

We are an AI-native software studio from Slovakia. Our team works on the projects with AI agents. Every project is led by an experienced developer and Digitaliko answers for the result. The software is yours from day one: code, documentation and decisions live in your repository, so another developer can take over at any time.

## What we build

- Custom web apps and internal tools
- AI agents that take routine work off a team, with exceptions going to a person
- Internal apps and agents for teams outside IT, running in your own cloud

## Open source

- [claude-code-production-starter](https://github.com/Digitaliko/claude-code-production-starter): Next.js starter with the guardrails AI agents need in production
- [superfaktura-mcp](https://github.com/Digitaliko/superfaktura-mcp): MCP server for the SuperFaktura invoicing API
- [car-logos-dataset](https://github.com/filippofilip95/car-logos-dataset): car brand logos in several sizes with a JSON index
